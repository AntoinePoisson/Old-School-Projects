Fichiers   : tree.c, other_fonction.c

BUT DU PROJET
Ecrire une fonction tree(int size) qui affiche en ASCII un sapin dont la
taille est donnee en parametre. Le commentaire d'en-tete des deux fichiers
le dit explicitement : "Write a function that displays a fir tree, based on
its given size."

CE QUE FAIT LE CODE
- first_line()      : calcule la position horizontale du sommet du sapin et
                      affiche la premiere ligne (la pointe).
- print_star_line() : affiche une ligne de '*' de longueur donnee.
- espace_line()     : gere l'indentation de chaque ligne pour centrer le motif.
- change_line()     : passe a la branche suivante.
- print_tree()      : boucle principale, empile les etages de branches ; la
                      largeur croit de 2 en 2 et redemarre plus haut tous les
                      4 niveaux pour dessiner les etages superposes du sapin.
- tronc()           : dessine le tronc en '|' sous le feuillage, avec un cas
                      particulier selon la parite de size.

Aucun main() n'est present : c'est une fonction a rendre, testee par la
moulinette. Pas de Makefile dans le dossier.
