Projet     : solostumper 2 - palindrome
Module     : B-CPE-130 - B1 Solo Stumpers (module "Acquis", pas de note

Langage    : C (Makefile, lib maison, write() uniquement pour l'affichage)

BUT DU PROJET
Determiner si une chaine de caracteres passee en argument est un palindrome.

USAGE
    ./solostumper <chaine>

COMPORTEMENT
- Si l'argument manque : ecrit "Error: missing arguments.\n" sur la sortie
  d'erreur (fd 2) et retourne 84.
- Si la chaine est un palindrome : affiche "palindrome!" sur stdout.
- Sinon : affiche "not a palindrome.".

CE QUE FAIT LE CODE
- check_error.c : verifie le nombre d'arguments.
- palindrome.c  : compare la chaine a son miroir et renvoie 1 / 0.
Le projet est volontairement minimal, typique d'un stumper court.

  d'ignorer espaces, casse ou ponctuation (le code ne le fait pas).
