SUJET NON TROUVE
================

Aucun sujet officiel n'a ete retrouve dans Project/ pour ce projet.
Ce fichier a ete redige par retro-analyse du code source (il ne remplace
pas le sujet d'origine et peut contenir des approximations).

Projet     : duostumper 3 - chiffre de Cesar
Module     : B-CPE-210 - B2 Stumpers (module "Acquis", pas de note lettre :
             aucun grade.txt n'est ecrit pour ce projet)
Langage    : C (Makefile, lib maison, get_next_line)

BUT DU PROJET
Chiffrer et dechiffrer un texte avec le chiffre de Cesar (decalage de
l'alphabet).

USAGE (deduit de main.c et check_if_encrypt.c)
    ./cesar <fichier> <decalage>          -> dechiffre le contenu du fichier
    ./cesar <option> ... <decalage>       -> chiffre (mode detecte par
                                             check_if_encrypt())
Le programme distingue deux "cas" : si check_if_encrypt() renvoie une valeur
non nulle et differente de 84, il appelle encrypting() ; sinon il dechiffre.

CE QUE FAIT LE CODE
- check_error.c        : validation des arguments, sortie 84 sinon.
- create_tab_alpha()   : construit la table de l'alphabet servant au decalage
                         (allouee dynamiquement, erreur "Failure Malloc.").
- take_data_of_file()  : lit tout le fichier via get_next_line
                         (erreur "Cannot read in file.").
- cesar_encrypt.c / cesar_decrypt() : applique le decalage dans un sens ou
                         dans l'autre en s'appuyant sur la table alphabet.
- Le resultat est affiche sur la sortie standard (my_putstr).

POINTS INCERTAINS
- La ligne de commande exacte (position et forme du flag de chiffrement) est
  deduite du code et non d'un enonce.
- Le sujet demandait peut-etre aussi une attaque par force brute sur les 26
  decalages ; rien de tel n'apparait dans le code.
