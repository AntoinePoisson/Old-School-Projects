Project description: IoT Project
In this module, you will each have to deliver an IoT project, involving at least :
- Connecting a device to a wifi network using the AP mode of the microcontroller
- Sensing Data (From a sensor, a weather API, both..)
- Use of a Micro-controller or a Single Board Computer (Or both)
- An interface (Web page, mobile app)
- Interfaces using physical buttons will be considered
