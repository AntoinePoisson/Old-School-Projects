BUT DU PROJET
Ce dossier n'est pas un projet Epitech mais le suivi complet d'une formation
en ligne : "Three.js Journey" de Bruno Simon. Chaque sous-dossier est le
code d'une lecon, numerote comme dans le cours, avec son propre
package.json / vite.config.js.

CONTENU (42 lecons conservees, de 03 a 54)
- Bases WebGL/Three.js : 03-basic-scene, 04-local-server, 07-cameras,
  12-materials, 13-3d-text, 15-lights, 16-shadows.
- Projets d'application : 17-haunted-house, 18-particles,
  19-galaxy-generator, 20-scroll-based-animation, 21-physics,
  22-imported-models, 23-raycaster-and-mouse-events,
  24-custom-models-with-blender, 25-realistic-render,

- Shaders GLSL : 27-shaders, 28-shader-patterns, 29-raging-sea,
  30-animated-galaxy, 31-modified-materials, 32-post-processing,
  33-performance-tips.
- Integration : 34-intro-and-loading-progress, 35-mixing-html-and-webgl,
  36 / 38 / 39 (creation, import et optimisation d'une scene faite sous
  Blender).
- React Three Fiber : 42-first-react-application a 54-create-a-game-with-r3f
  (drei, debug, environnement, chargement de modeles, texte 3D, portail,
  evenements souris, post-processing, portfolio, physique, jeu).
